# Cisco Packet Tracer Network

This folder contains the Cisco Packet Tracer network topology used for the project.

## Network Components

- Cisco 2911 Router
- Cisco 2960 Switch
- 4 PCs
- 1 Server

## Traffic Types

The network is configured to generate and demonstrate:

- HTTP
- DNS
- FTP
- ICMP

## Purpose

Cisco Packet Tracer is used to simulate the network environment and visualize packet movement using Simulation Mode.
