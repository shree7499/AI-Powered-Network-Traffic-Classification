# Source Code

This folder contains the Python source code for the AI-powered network traffic classification system.

## Planned Files

### preprocessing.py
Preprocesses network traffic data and prepares features for the Transformer model.

### transformer_model.py
Defines the Transformer-based deep learning model for traffic classification.

### train.py
Trains the Transformer model using the prepared network traffic dataset.

### predict.py
Uses the trained model to classify new network traffic.

## Traffic Classes

The model will classify network traffic into:

- HTTP
- DNS
- FTP
- ICMP
