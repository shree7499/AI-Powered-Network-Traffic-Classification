# Network Traffic Dataset

This folder contains the dataset used for the AI-powered network traffic classification system.

## Traffic Classes

The project focuses on the following network traffic types:

- HTTP
- DNS
- FTP
- ICMP

## Traffic Features

The dataset can contain features such as:

- Source IP
- Destination IP
- Source Port
- Destination Port
- Protocol
- Packet Count
- Packet Size
- Total Bytes
- Flow Duration
- Packet Rate
- Byte Rate
- TCP Flags
- Traffic Label

## Purpose

The dataset is used to preprocess network traffic information and prepare it for training and evaluating the Transformer-based traffic classification model.
